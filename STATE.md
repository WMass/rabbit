## Physics implemented (and its provenance)

Born-level neutral-current Drell-Yan mass spectrum, ported verbatim from
`hard_me` in
`/work/submit/david_w/ZMass/calibration_studies/lineshape/zwidth_sensitivity.py`
(which builds on `drell_yan_xsec.py` / `constants.py` in the same directory):

```
dsigma/dm = 2 m C sum_f L_f(m^2) [ e_f^2/(2 m^4)
            + sum_{g in gL,gR} ( Re[chi] (1-4s2)/(4 s2 (1-s2)) e_f g
                               + |chi|^2 (1+(1-4s2)^2)/(32 s2^2 (1-s2)^2) g^2 ) ]
|chi|^2 = 1/((m^2-m_Z^2)^2 + (m_Z Gamma_Z)^2)     "fixed"   (default)
          1/((m^2-m_Z^2)^2 + (m^2 Gamma_Z/m_Z)^2) "running"
```

* EW scheme: Gmu. `G_F = 1.1663787e-5`, `m_W = 79.906853549493746`,
  `m_Z(fixed) = 91.153509740726733`, `Γ_Z(fixed) = 2.4932`,
  `sin^2 = 1 - m_W^2/m_Z^2 = 0.23152`, `alpha(m_Z) = sqrt(2) G_F m_W^2 sin^2/pi`.
  These are the DYTurbo CT18Z `.in` values copied from `constants.py`.
  `sin^2` does **not** track a fitted `m_Z`; it is a fixed input (optionally a
  fitted nuisance via `sin2_param`).
* Parton luminosity: LO, per flavour d,u,s,c,b, `mu_F = Q`, NNPDF3.1 NNLO
  `as=0.118` member 0, sqrt(s) = 13 TeV, 300 log-spaced anchors over
  40–200 GeV, **fully inclusive in rapidity** (a `--y-cut` option exists but is
  off). Generated by `make_lumi_table.py` importing
  `drell_yan_xsec.integrate_sigma_hat_prime_sm` so the table is bit-identical
  to the reference study's.
* **Not** included: FSR (that is `MassCFTerm`'s separate `phi_K`), acceptance,
  EW loop corrections, running alpha/sin^2, QCD beyond what the PDF absorbs.

## From lineshape to CF (the numerics)

pdf = spectrum truncated to `window` (default 50–130 GeV) and renormalised,
sampled on `nm` uniform points, represented by its piecewise-linear
interpolant with the outermost node on each side forced to 0 (so the edge is a
one-bin ramp, ~5 MeV, and the represented pdf is exactly normalised).
The hat-basis CF is analytic, so

```
phi(tau) = dm K(tau dm) e^{i tau (m_lo - m_ref)} conj(rfft(pad(p))[j])
K(x) = (sin(x/2)/(x/2))^2,  tau_j = 2 pi j / (nfft dm)
```

then a 4-point Lagrange interpolation onto the per-candidate `t/sigma`. The
tabulation carries an extra node at `tau = -dtau` (free: `phi(-tau) =
conj phi(tau)`) so the stencil reaches `tau = 0`.

**This was the one real bug found and fixed**: clamping the stencil at
`tau = dtau` instead left an O(dtau^2) error on the most heavily weighted point
of the inverse transform, which dominated everything (smeared density error
1.5e-3 instead of 1.5e-8).

Defaults: `nm=16384` (dm = 4.88 MeV), `nfft=16*nm` (dtau = 4.91e-3 GeV^-1),
`tau_max=40` GeV^-1, `m_ref=91.1876`, `width_scheme="fixed"`.

## Ideas not pursued

* The kernel returns `(log|phi|, arg phi)` and `MassCFTerm` immediately does
  `exp(log|phi|) cos(arg phi + ...)`, i.e. a `log`/`atan2`/`exp` round trip on
  n*nt elements. An optional `(re, im)`-returning kernel contract would drop
  four transcendentals per element and speed the Z term up materially. That is
  a change to `MassCFTerm`, so it was left alone.
* The Hessian memory (78 GB at n=200k, nt=256) is the autodiff tape over all
  chunks. `trust-krylov` with HVPs would avoid it.

## What is still missing for a real data Z channel

* **FSR kernel for the Z** — `phi_K` must be tabulated from the generator
  (POWHEG+MiNNLO+Photos), as the J/psi channel does. The provider is pre-FSR by
  construction.
* **Acceptance `A(m)`** — lepton pT/eta cuts make the observed spectrum
  `A(m) dsigma/dm`; the provider has no lepton-angular information at all. The
  luminosity generator's `--y-cut` covers only boson rapidity.
* **Background** — `UniformBackground`/`BernsteinBackground` already exist in
  `MassCFTerm`; a Z channel needs a real shape and a floating fraction.
* **Per-candidate resolution from CVH on Z tracks** — the `families` /
  `sigma` / `vgf` arrays, i.e. the same export path as the J/psi channel.
* **Theory nuisances** — PDF (regenerate the table per replica / eigenvector
  and interpolate, or add a luminosity-shape nuisance), EW corrections,
  running-vs-fixed width convention, alpha and sin^2 running.
* **A mass window on `m_obs`** would need the truncated-likelihood
  normalisation, as `tests/test_unbinned_mass.py` test 4 does for the
  Breit-Wigner. The toy in test 4 deliberately applies no `m_obs` cut so the
  model is exactly normalised.
* `m_Z` and the momentum-scale parameter `alpha` are exactly degenerate in a
  single-resonance fit; a Z channel only measures `m_Z` jointly with the J/psi
  (or another) channel that fixes the scale.
